# Music bank

`<mood>/<name>.mp3` + `<name>.json` (must contain `"licence"`). Filled weekly by the **Music bank** workflow with
original tracks from ACE-Step 1.5 (MIT). You can add your own: only music you own or that is CC0, and never tracks
registered in YouTube Content ID (many "free" stock-music tracks are, and they get claimed).

Moods: awe, mystery, investigate, tension, triumph, upbeat, melancholy.
